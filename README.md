# Katra & Augustine Portfolio Website

## Live demo link 
https://itskhadra.github.io/portfolio-website/

## About the Project

This project is a personal portfolio website created by **Katra Muhidin and Augustine** as a group project.

The purpose of this project is to demonstrate our understanding of **HTML, CSS, and JavaScript** by building and deploying a responsive single-page portfolio website.

The website introduces us, showcases our skills and projects, and provides a way for visitors to contact us.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

The website includes:

* Basic JavaScript functionality

## How to Run the Project

1. Clone the repository:

```bash
git@github.com:itskhadra/portfolio-website.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
